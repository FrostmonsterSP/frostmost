## Концепция

Знак объединяет два образа: **горный пик** (Frost) и **арочный проход / мост** (Most).
Две формы, строгая симметрия, один цвет. Спокойствие и надёжность без техничности.

## Брендовый цвет

Один цвет, пара по темам. **Градиента нет ни в одной версии.**

| Токен | Светлая тема | Тёмная тема |
|---|---|---|
| Знак | `#3D57B2` | `#3550B8` |
| Знак на акценте | `#FFFFFF` | `#FFFFFF` |
| Монохром | `#1C1B1F` | — |

Это акцент подписки №0 из кода приложения (`HOME_ACCENTS[0]` / `HOME_ACCENTS_DARK[0]`).
Новых синих в продукт не вводится. `primary` приложения (`#0B57D0`) остаётся отдельной ролью
«главное действие» и не меняется.

Почему не `#0B57D0` как знак: в тёмной теме `primary` равен `#AAC7FF`, что на белом даёт
`1.70:1` — как графика не читается. У акцента 0 есть светлая и тёмная пара по построению.

### Знак

Геометрия на холсте `0 0 100 100`, симметрия по `x=50`, ровно две формы:

```
пик : M 50 14 L 64 30 L 86 44 L 14 44 L 36 30 Z
арка: M 14 86 A 36 26 0 0 1 86 86 L 72 86 A 22 14 0 0 0 28 86 Z
```

| Свойство | Значение |
|---|---|
| Зазор пик ↔ арка | 16 единиц |
| Габарит | 14..86 по обеим осям |
| Минимальная толщина | 6 единиц |
| Форм | 2 |

Плечо пика на `y=30` — сознательное решение. При габарите 72×72 чистая треугольная вершина
математически выходит тупой (93–108°), поэтому основание расширено: верхний апекс острый (82°),
силуэт читается как спокойная гора. Это соответствует брифу («спокойствие, не техничность»).

### Проверка 24 px

Знак отрисован в 24, 48, 96 px и просмотрен с увеличением ×8 без сглаживания: зазор между пиком
и аркой остаётся отдельным разрывом. Доказательства — `proof/mark-24-x8.png`, `proof/app-icon-24-x8.png`.

## Что не проверено

| Проверка | Статус | Причина |
|---|---|---|
| Safe zone на реальном Android-устройстве | **Not run** | замер по растеризации; устройство не подключалось |
| Маски «капля» Samsung и шестиугольник | **Not run** | эмуляция маски — только круглая |
| Отображение иконки на белом и тёмном фоне лончера | **Not run** | нужен экран устройства |
| Читаемость при 24 px на конкретной прошивке | **Not run** | зависит от DPI и сглаживания |
| Баннер репозитория 1280×640 | **не сдан** | в объём v2 не входил |
| PNG-набор для магазина (512) | **не сдан** | рендерится из SVG, отдельными файлами не поставляется |
| Печатная версия | **не сдана** | CMYK и кривизна сверх контура не проверялись |

Отсутствие PNG-размеров не блокирует использование: `rsvg-convert` даёт любой размер из SVG
без потери качества.
