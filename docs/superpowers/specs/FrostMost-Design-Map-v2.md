# FrostMost — карта целевого дизайна главного экрана

**Версия:** 2.0  
**Дата:** 2026-11-08  
**Статус:** утверждённое продуктовое решение; ещё не подтверждено реализацией.

Документ описывает целевую архитектуру интерфейса FrostMost. Текущие размеры и цвета существующих
компонентов остаются зафиксированы в исходной карте `2026-11-08-fork-ui-design-map.md`.
Этот документ не выдаёт целевое поведение за уже реализованное.

## 1. Принцип главного экрана

Главный экран строится по модели **Fixed Connection Area + Scrollable Configuration Area**:

- верхняя зона подключения остаётся неподвижной при обычной прокрутке конфигурации;
- нижняя зона настроек прокручивается и содержит раскрываемые секции;
- выбор сервера и маршрутизации происходит прямо на главном экране;
- серверная шторка и её peek-состояние больше не являются частью целевого UX.

Пользователь всегда должен быстро понимать три независимые вещи:
1. состояние VPN;
2. выбранную подписку;
3. выбранный сервер.

Эти состояния нельзя визуально смешивать.

## 2. Каркас экрана

```text
┌──────────────────────────────────────┐
│ FrostMost                 Добавить   │  неподвижная зона
│ [Подписка A] [Подписка B]            │  если подписок > 1
│ ┌──────────────────────────────────┐ │
│ │ Название подписки      Настроить │ │
│ │ Трафик / срок                   │ │
│ │ [ VPN ]          Подключено      │ │
│ │                  Сервер           │ │
│ └──────────────────────────────────┘ │
│ [Обновить] [Кабинет] [Поддержка]     │
│ [Сообщение или проблема, если есть]  │
├──────────────────────────────────────┤
│ Маршрутизация                  ⌄     │  прокручиваемая зона
│   ○ Режим A                          │
│   ● Режим B                          │
│ Серверы                        ⌄     │
│   [Поиск серверов…]                  │
│   Сервер A                      ✓    │
│   Сервер B                           │
│   Сервер C                           │
└──────────────────────────────────────┘
```

## 3. Неподвижная зона подключения

Порядок блоков:

1. **Верхняя панель (`HomeTopBar`)** — название FrostMost, «Добавить», «Ещё».
2. **Ряд подписок (`HomeSubscriptionRow`)** — только если подписок больше одной.
3. **Карточка подписки (`HomeSubscriptionCard`)** — имя, трафик и срок при наличии, действие VPN,
   статус и текущий сервер.
4. **Ряд быстрых действий (`HomeActionRow`)** — обновить, кабинет, поддержка согласно доступным
   данным подписки.
5. **Сообщение/проблема (`HomeIssueStrip`, `HomeAnnounceStrip`)** — только при наличии содержимого.

Правила:
- Зона не прокручивается вместе со списком серверов на обычном портретном экране.
- Не задавать фиксированную общую высоту: высота зависит от реального содержимого.
- Не резервировать пустое место под отсутствующее сообщение.
- Не обрезать карточку и не уменьшать системный размер шрифта ради фиксации зоны.
- Короткое сообщение показывается целиком; длинное — как превью с явным раскрытием.
- Основное действие VPN должно оставаться визуально главным.
- Ошибка объясняет, что произошло и что пользователь может сделать; действие размещается рядом
  или подсвечивается в ряду действий.

## 4. Прокручиваемая зона конфигурации

Зона содержит две inline-секции, раскрывающиеся вниз.

### 4.1 Маршрутизация

- Заголовок содержит название секции, краткое текущее значение и индикатор раскрытия.
- Нажатие раскрывает список режимов непосредственно под заголовком.
- Повторное нажатие сворачивает список.
- Выбранный вариант отмечается не только цветом: нужны текстовое/иконное состояние и semantics.
- После выбора краткое значение в заголовке обновляется.
- Набор режимов, алгоритм маршрутизации и формат хранения не меняются.

### 4.2 Серверы

- Заголовок содержит «Серверы», имя выбранного сервера и индикатор раскрытия.
- Нажатие раскрывает список на месте, без `ModalBottomSheet`.
- В раскрытой секции доступны поиск, проверка и список серверов.
- Основное нажатие строки выбирает сервер.
- Вторичные действия — поделиться, изменить, удалить — находятся в overflow menu.
- Удаление визуально и интерактивно отделено от выбора.
- Выбранный сервер отмечен понятным состоянием, а не только цветной полосой.
- Технические детали (адрес, порт, протокол, транспорт) вторичны по отношению к имени.
  Их можно показывать компактно или переносить в подробности.
- Перезапуск доступен только при активном VPN; disabled-состояние объясняется TalkBack.
- Проверка сервера не меняет выбор и не запускает VPN.

## 5. Прокрутка и состояние

- В обычном режиме главный экран имеет одного владельца вертикальной прокрутки.
- Не вкладывать вертикальный `LazyColumn` списка серверов в другой вертикальный scroll container
  без отдельного обоснования и проверки.
- Предпочтителен единый lazy-контейнер с секциями и стабильными ключами.
- Идентичность серверов — GUID, групп — ID; не использовать индексы списка.
- Сворачивание секции не должно сбрасывать подписку, выбранный сервер, режим маршрутизации,
  поисковый запрос или состояние VPN.
- Позиция списка по возможности сохраняется при временном сворачивании секции.
- Back не должен отключать VPN. Поведение Back при раскрытой секции согласовать с общей
  навигацией приложения.

## 6. Адаптивность

Неподвижная зона — приоритет для обычного портретного сценария, но не ценой доступности.

Проверить:
- компактную высоту экрана;
- ширину 320 dp;
- landscape;
- split-screen / multi-window;
- увеличенный font scale;
- открытую IME при поиске серверов.

Если верхняя зона не помещается, допустим fallback:
- весь экран становится единым вертикально прокручиваемым экраном; или
- конфигурация открывается отдельным полноэкранным destination.

Нельзя:
- обрезать основное действие;
- уменьшать системный размер шрифта;
- оставлять элементы недоступными;
- допускать перекрытие поля поиска клавиатурой.

## 7. Что остаётся неизменным

- VPN-ядро, сетевые протоколы и режимы работы;
- алгоритмы маршрутизации и доступные режимы;
- формат подписок, сериализованные поля и существующее хранилище;
- импорт/экспорт конфигураций;
- независимые сценарии «Добавить», «Ещё» и другие модальные задачи;
- функциональные возможности базового приложения.

## 8. Визуальные ориентиры

Сохраняются ранее зафиксированные принципы FrostMost:
- акцентный цвет выбранной подписки;
- контрастный текст на акценте;
- Material 3 и системная типографика;
- сетка с базовым шагом 8 dp и боковыми отступами 16 dp;
- светлая и тёмная темы;
- ясная иерархия: VPN-действие > статус подключения > быстрые действия > конфигурация.

Точные значения существующих компонентов не переопределяются этим документом без необходимости:
сначала следует переиспользовать текущие размеры, цвета и токены.

## 9. Отличия от текущего состояния

| Сейчас | Целевое состояние |
|---|---|
| `BottomSheetScaffold` и шторка серверов | Inline-секция «Серверы» |
| Выбор сервера в отдельной шторке | Выбор на главном экране |
| Маршрутизация отдельным окном/переходом | Inline-секция «Маршрутизация» |
| Основной экран и список серверов конкурируют за пространство | Верхняя зона подключения + нижняя зона конфигурации |
| Высота верхней зоны не закреплена как принцип | Верхняя зона неподвижна на типичном портретном экране |
| Возможна отдельная прокрутка списка | Один вертикальный scroll owner в обычном режиме |
